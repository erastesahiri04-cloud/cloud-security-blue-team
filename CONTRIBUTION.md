# Contribuer

Merci d'envisager de contribuer !

Processus rapide :
1. Ouvre une issue pour discuter de changements importants.
2. Crée une branche nommée `feat/xxx` ou `fix/xxx`.
3. Soumets une Pull Request décrivant les changements.
4. Respecte le style du repo (markdown linting via Super-Linter).

Pour les rapports de sécurité, utilise l'adresse indiquée dans SECURITY.md.
