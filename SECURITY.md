# Security Policy

Merci de votre intérêt pour la sécurité de ce projet.

Pour signaler une vulnérabilité de sécurité, merci d'envoyer un e‑mail à: erastesahiri04@.com avec:
- Description courte
- Étapes pour reproduire
- Gravité approximative
- Preuve de concept (si possible)

Ne publiez pas de détails de vulnérabilité publiquement (issues publiques). Nous traiterons les rapports en privé et fournirons un suivi.
